# CyberRecon Suite - FAQ

## Frequently Asked Questions

### General Questions

**Q: What is CyberRecon Suite?**
A: CyberRecon Suite is a comprehensive cybersecurity operations platform that unifies SIEM, EDR, threat intelligence, penetration testing, and compliance management in a single interface.

**Q: What platforms does CyberRecon Suite support?**
A: CyberRecon Suite runs on Windows 10+, macOS 12+, and Linux (Ubuntu 20.04+).

**Q: Is CyberRecon Suite free to use?**
A: Yes, we offer a free tier with basic monitoring capabilities for up to 1,000 events per day. Professional and Enterprise plans are available for advanced features.

### Installation & Setup

**Q: How do I install CyberRecon Suite?**
A: Download the latest release from our GitHub releases page, or build from source using our build scripts. See the [Installation Guide](#-installation) for detailed instructions.

**Q: What are the system requirements?**
A: Minimum 8GB RAM, 2GB storage, and a modern processor. See our [Installation Guide](#-installation) for complete requirements.

**Q: Can I run CyberRecon Suite in Docker?**
A: Docker support is planned for a future release. Currently, native installation is supported.

### Features & Functionality

**Q: What penetration testing tools are included?**
A: CyberRecon Suite includes WiFi/Bluetooth security testing, network scanning, web application testing, and password security tools. All tools require proper authorization.

**Q: Does CyberRecon Suite integrate with other security tools?**
A: Yes, we provide extensive API support and integrations with popular security tools and threat intelligence feeds.

**Q: Can I customize dashboards and reports?**
A: Professional and Enterprise plans include custom dashboard creation and advanced reporting capabilities.

### Support & Troubleshooting

**Q: Where can I get help?**
A: Free users can access community support through GitHub Discussions. Professional and Enterprise users receive direct technical support.

**Q: How do I report a bug or request a feature?**
A: Please use our GitHub Issues for bug reports and GitHub Discussions for feature requests.

**Q: Is there documentation available?**
A: Yes, comprehensive documentation is available in the `/docs` directory and linked throughout this README.

### Licensing & Legal

**Q: What license does CyberRecon Suite use?**
A: CyberRecon Suite is released under the MIT License with additional terms for penetration testing tools.

**Q: Can I use CyberRecon Suite commercially?**
A: Yes, the MIT License permits commercial use. See the [License](#-license) section for complete terms.

**Q: Are the penetration testing tools legal to use?**
A: The tools are legal when used with proper authorization. Users must obtain explicit permission before testing any systems. See our [Security Disclaimer](DISCLAIMER.md) for complete legal guidelines.
