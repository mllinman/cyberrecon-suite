# CyberRecon Suite Assets

This directory contains visual assets for the CyberRecon Suite project.

## Files

- `header-banner.svg` - Main project banner/header image
- `logos/` - Different logo formats and sizes
- `screenshots/` - Application screenshots and previews
- `badges/` - Status badges and shields
- `architecture/` - Technical architecture diagrams

## Usage

These assets are used in:
- Main README.md
- Documentation files
- Website and marketing materials
- GitHub social preview
